# TaskBloom — TypeTasks project

A small task tracker made with plain HTML, CSS, and TypeScript. It supports adding tasks, moving them between `todo`, `in-progress`, and `done`, filtering, and deleting.

## Files

- `index.html` — page structure
- `styles.css` — responsive styling
- `model.ts` — typed `Task` model and operations
- `app.ts` — typed DOM events and rendering
- `tsconfig.json` — TypeScript compiler settings
- `app.js` and `model.js` — generated by `tsc` (commit these for static hosting)

## Run locally

1. Install Node.js, then open a terminal in this folder.
2. Install TypeScript if needed: `npm install --global typescript`
3. Compile: `tsc`
4. Start a local static server (recommended, because the app uses JavaScript modules). If Python is installed, run `python -m http.server 8000`.
5. Open `http://localhost:8000` in your browser.

Check that you can add, advance/reopen, delete, and filter tasks.

## Publish with GitHub Pages

1. Create or use your **Part 1 public repository**. If you already have `model.ts` and `tsconfig.json`, compare them with this example and keep your Part 1 model if required by your instructor.
2. Copy the files into that repository. Run `tsc` and make sure there are no errors; this creates `app.js` and `model.js`.
3. Create a branch: `git checkout -b part-2-ui-ship`
4. Commit and push the files, including generated `.js` files.
5. On GitHub, open **Settings → Pages**, select the `main` branch (or the branch your course requires) and save.
6. Open the published URL and test it on another browser/device.
7. Open a pull request from `part-2-ui-ship` into `main`. Include both the repository URL and live URL in the PR description.
8. Submit the pull-request URL in Kalvium.
